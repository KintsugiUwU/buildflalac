flalac for Mac

A small AppleScript that keeps the Music app (or iTunes) on a Mac in step with this mirror: it adds new songs, removes deleted ones, follows renamed ones without losing their plays, refreshes retagged ones{% if jellyfin %} and syncs play counts with Jellyfin both ways{% endif %}. It works on every Mac from Mac OS X 10.4 to today.

  1. In Music or iTunes, open Settings → Files and turn off Copy files to Music Media folder when adding and Keep Music Media folder organised.
  2. Connect the share that holds the mirror (Finder → Go → Connect to Server).
  3. Download the script, open it in Script Editor and choose File → Export (or Save As) → File Format: Application.
  4. Run the app. The first time it asks where the mirror folder is on this Mac. Run it again whenever you like, or after syncing an iPod.
{% if not jellyfin %}

Play counts: set JELLYFIN_URL, JELLYFIN_API_KEY and JELLYFIN_USER to sync them with Jellyfin.
